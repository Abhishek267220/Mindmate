ℹ️ About MindMate

Learn about the purpose of this project, the technologies used, and how it was built as a college assignment.

🎓 About This Project

MindMate – Student Study & Wellness Hub.


College life can be stressful. Between assignments, exams, and new subjects, students often forget about mental wellness too. MindMate brings study planning and wellness together in one friendly website.

🎯 Purpose & Objectives

The main goals of this project were:

  • Learn and practise the basics of HTML, CSS, and JavaScript
  • Create a multi-page website with consistent design and navigation
  • Understand how pages link to each other using anchor tags
  • Use CSS for layout, colours, fonts, and responsive design
  • Use JavaScript to add interactivity (task list and mood tracker)
  • Build something useful and presentable for a college submission

✨ Features of MindMate

  • Home Page with hero section and feature cards
  • Study Planner with timetable and interactive task checklist
  • Mood Tracker with emoji buttons and motivational messages
  • AI Learning Corner explaining AI, ML, and Deep Learning simply
  • About Page with project details and tech stack
  • Responsive design for mobile, tablet, and desktop

🛠️ Technologies Used

This project uses only three core web technologies — no frameworks or libraries!

📄 HTML5 🎨 CSS3 ⚡ JavaScript 🔤 Google Fonts (Poppins) 🖥️ VS Code 🔌 Live Server

📄 HTML – Creates the structure of every page: headings, paragraphs, tables, buttons, and links.


🎨 CSS – Makes the site look attractive. Controls colours, fonts, layout, shadows, and hover effects.


⚡ JavaScript – Adds interactivity: the task list, mood tracker messages, and mobile hamburger menu.

📚 What I Learned

  • How to structure HTML with proper tags (nav, section, footer, table)
  • How to link multiple pages together with anchor tags
  • How to use CSS variables for consistent colours
  • How to use Flexbox and Grid for page layouts
  • How to make a website responsive using media queries
  • How to select and modify HTML elements using JavaScript (DOM)
  • How to handle button clicks with addEventListener
  • How to add items dynamically using createElement and appendChild
